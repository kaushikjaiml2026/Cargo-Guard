
# CargoGuard

## Intelligent Load Safety Monitoring for Heavy Vehicles

CargoGuard is a software prototype designed to monitor vehicle cargo loads, identify potential load-related safety risks and generate alerts.

## Features

- Fleet monitoring dashboard
- Vehicle load analytics
- Overload detection
- Uneven load detection
- Cargo movement simulation
- Safety alerts and history
- PDF safety reports
- CSV fleet data export

## Technologies

- React.js
- CSS
- Python
- Flask
- REST API

## Project Structure

- frontend/
- backend/

## Purpose

To demonstrate how software-based monitoring can support safer transportation and logistics.

## Disclaimer

This is an educational prototype using synthetic sensor data. It is not certified for real-world vehicle safety decisions.
